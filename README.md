this repo contains various ksu implementations for the sony xz1c (lilac)
originally forked from whatawursts lineage 21 kernel
branches marked with -23 are forked from sunplex07

# building
run the build-kernel workflow and select your flavour
| Flavour | Description |
| :---: | :--- |
| **vanilla** | regular lineage 23 kernel, no root |
| **old-spice** | regular lineage 21 kernel, no root |
|  |  |
| chocolate | l23, kernelsu-next |
|  |  |
| **strawberry** | l23, sukisu-nova |
| eton-mess | l23, sukisu-nova, susfs |
| coffee | l23, bakasu |
| tiramisu | l23, bakasu, susfs |
|  |  |
| raspberry | l23, droidspaces, sukisu-nova |
